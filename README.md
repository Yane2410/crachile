# CRA — Comer · Rezar · Amar
Menú digital (pedido por WhatsApp) de Comer Rezar Amar.

## Cómo correrlo
```bash
npm install
npm run dev
```
Abre http://localhost:8080

- Menú: `/`
- Pedido: `/pedido`
- Cocina: `/admin`

## Notas
- Los precios se calculan en el servidor, no en el navegador.
- El PIN de cocina se configura en el panel; no va en este zip.
- Fotos del menú: `public/menu/`
